# System Architecture

## 1. Overview

The Smart Campus Resource Booking System will follow a layered web application architecture. The system will separate the user interface, application logic, and database operations to improve maintainability and organization.

The application will allow students and faculty members to interact with the system through a web browser. Requests from the user interface will be processed by the Java-based backend, which will implement the required business logic and communicate with the Oracle Database.
