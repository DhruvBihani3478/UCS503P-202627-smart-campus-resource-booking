# Smart Campus Resource Booking System

A web-based resource booking and management system developed as a semester project for **UCS503: Software Engineering** at **Thapar Institute of Engineering and Technology**.

The project extends an existing Oracle-based Resource Booking System developed during the previous DBMS course into a complete software application with a web interface, application logic, authentication, booking workflows, resource management, conflict validation, and testing.

---

## Project Overview

Educational institutions have various shared resources such as classrooms, laboratories, seminar halls, projectors, and other facilities. Managing these resources manually or through disconnected systems can lead to scheduling conflicts, inefficient resource utilization, and difficulty in tracking reservations.

The **Smart Campus Resource Booking System** provides a centralized platform where users can:

- View available campus resources
- Check resource availability
- Submit booking requests
- Track booking status
- Manage their bookings

Administrators can:

- Manage campus resources
- Manage users
- Review booking requests
- Approve or reject bookings
- Monitor resource utilization
- View booking records and reports

The system is designed to reduce booking conflicts and make campus resource management more efficient.

---

## Project Background

The project builds upon an existing **Resource Booking System developed as a DBMS project using Oracle Database**.

The previous project primarily focused on:

- Database design
- Tables and relationships
- SQL operations
- Data storage and management
- Resource and booking records

The current project extends this foundation into a complete software system by introducing:

- Web-based user interface
- Java application layer
- User authentication
- Role-based access
- Booking workflows
- Automated conflict validation
- Administrative functionality
- Testing and validation
- Software engineering documentation
